Aperçu des carrousels — rendu final

Cette page affiche les PNG réellement déployés sur perfeco.nc, c'est-à-dire exactement ce qui sera publié sur LinkedIn et Facebook. C'est la seule vue fidèle : elle ne dépend d'aucun fichier local.

Pourquoi cette page existe. Ouvrir directement un carousel-*.html dans l'aperçu ne montre pas les photos : le fichier y est chargé comme une URL data:, qui n'a pas de dossier de base — aucun chemin local (ni file:///, ni relatif) ne peut s'y résoudre. Seules les URL https:// absolues s'y chargent, ce qui explique que le logo apparaisse et pas les photos. L'export Puppeteer, lui, n'a pas cette limite : les PNG ci-dessous le prouvent.

À utiliser pour relire une semaine avant publication. Pour une nouvelle semaine, dupliquer un bloc ci-dessous et remplacer W33 par le dossier voulu.
